# Rectangle configuration

My Rectangle settings and keyboard shortcuts, exported from Rectangle **0.49 (54)** on 2026-10-20.

## Backup

`RectangleConfig.json` is the native export from Rectangle Preferences. It includes the shortcuts and settings, such as launch on login, the hidden menu bar icon, zero window gaps, and the 400 px Todo width.

## Restore

1. Open Rectangle Preferences.
2. Open **Settings**.
3. Select **Import** and open `RectangleConfig.json`.

## Update

Use **Settings → Export** to replace `RectangleConfig.json`, then commit and push the file.
